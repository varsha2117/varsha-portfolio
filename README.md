## Deploy to Vercel

### GitHub + Vercel

1. Create a new GitHub repository, for example `varsha-portfolio`.
2. Upload every file in this folder to the repository.
3. Sign in to Vercel using GitHub.
4. Select **Add New → Project**.
5. Import the `varsha-portfolio` repository.
6. Leave the build command empty.
7. Leave the output directory empty.
8. Click **Deploy**.
9. Vercel will provide your live `.vercel.app` URL.

Because this is a static HTML/CSS/JavaScript portfolio, no backend server is required for deployment.
